# AGI System — Resources, KPIs & Budget

## Technical Stack
- **Primary Model:** DeepSeek V3 or similar
- **Fallback:** Mistral Small
- **Databases:** PostgreSQL (structured), Redis (caching), Qdrant (vector embeddings)
- **Monitoring:** Prometheus + Grafana
- **Logging:** ELK Stack (Elasticsearch, Logstash, Kibana)
- **Security:** Vault for secrets, Fail2Ban for intrusion prevention
